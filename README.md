# Skystore - Django Project

Проект интернет-магазина Skystore, разработанный на Django с использованием Bootstrap для стилизации.


## Быстрый старт

### Установка


pip install django

## Или через poetry
poetry install


##  Технологии

- Python 3.10+
- Django 5.2.5
- Bootstrap 5.3.2
- SQLite (база данных по умолчанию)
